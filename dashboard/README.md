# Agent Dashboard

Local development dashboard for the OceanMain agent network.

## How to Run

You need **two terminals**:

**Terminal 1 — Backend (Node/Express):**

```
npm run dev:server
```

**Terminal 2 — Frontend (Vite/React):**

```
npm run dev
```

Then open your browser at `http://localhost:5173` (or whatever port Vite prints).

## Stack

- Frontend: React 19 + Vite
- Backend: Node.js / Express
